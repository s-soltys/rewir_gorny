# Legacy prototype media

These files were created or assembled for the retired Phaser/Ink prototype. They are retained as reference material, not approved final-game assets. The old TTS WAVs were known not to match the prototype's final dialogue; check provenance, quality, and licensing before reuse or publication.

- `legacy-prototype/images/scenes/` — background experiments and scene images.
- `legacy-prototype/images/sprites/` — prototype characters and hotspot sprites.
- `legacy-prototype/audio/` — old generated dialogue WAVs; unmatched to the final Ink text in the July 2026 audit.
- `legacy-prototype/audio-tests/` — generated test audio files.
- `mood-board/` — original visual reference image.

Do not treat a file here as evidence of canonical world detail. The source-of-truth documents are under `world/` and `docs/narrative/`.
