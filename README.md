# Rewir Górny — story preproduction

A grimdark, faction-driven interactive narrative set in Piła's Osiedle Górne during the 1990s. A copper-linked distortion of space and memory gathers around the neighborhood, but its ultimate nature remains unknowable.

**This repository is currently for worldbuilding and story design, not a runnable game.** The old Phaser/Ink prototype is being retired from the main working tree; its non-code assets and a short account of its playable flow are retained as reference. The project's later Godot/Dialogue Manager implementation was never committed to this repository.

## Canon discipline

- **CANON** means directly established by Szymon's decisions.
- **PROVISIONAL** means a useful proposal that still needs approval.
- **OPEN** means undecided; do not fill it in as fact.
- **ARCHIVED** means historical prototype material, not current canon.

Proposals never become canon silently. The decision log is the authority when documents disagree.

## Repository map

- `world/` — canonical and provisional world reference.
- `docs/narrative/` — premise, outline, reveal/clue map, scene cards, process, and archive.
- `assets/reference/legacy-prototype/` — retained art/audio from the earlier game prototype; not approved for the eventual game.
- `docs/style-guide.md` — provisional prose and interactive-writing guidance.
- `AGENT_INSTRUCTIONS.md` — repository workflow and guardrails.

The story should stay small enough to test. Expand the world only when it creates character pressure, plot movement, or a meaningful player choice.
